Install on iPhone

  1. Open this page in Safari.
  2. Tap ••• next to the address bar, then Share. (On older iPhones, tap Share directly.)
  3. Scroll down and tap Add to Home Screen.
  4. Keep Open as Web App switched on, then tap Add. If it's off, you get a plain bookmark instead.

It opens full screen and works without signal using the last menus it downloaded.

Show or hide

The buttons under the search box hide or show items that are Straight up (gluten free as served, or with any milk except the ones named), Needs change (ask for a swap or a change), or contain Gluten.

Reading the tags

  • Straight up gluten free with no changes
  • Any milk fine with any of the options shown
  • Swap normally comes with an option that has gluten, so ask for another
  • Ask gluten free only with the change shown
  • Wheat contains gluten whatever you order

Favourites

Open any item and tap ☆ Save. Favourites stay on this phone.

Staying up to date

The app checks for new menus each time you open it with signal. Tap ↻ to check now. If a restaurant's guide has passed its end date, you'll see a warning.

    Add a menu

    Uploading needs a one-time GitHub key for this app's project. It's saved on this phone only.

    1. In Safari, open github.com/settings/personal-access-tokens/new.
    2. Name it GF Menus upload and pick an expiry.
    3. Under Repository access, choose Only select repositories and pick gf-drinks.
    4. Under Permissions → Repository permissions, set Contents to Read and write.
    5. Tap Generate token, copy it and paste it below.

    Not the owner? Send menus to whoever shared this app with you.
