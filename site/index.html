Shared kitchens: restaurants prepare food and drink where allergens are handled, so nothing is guaranteed free from gluten. If you're coeliac, tell the staff when you order.

Unofficial guide made from each restaurant's published allergen information. Not affiliated with any restaurant.

Install on iPhone

  1. Open this page in Safari.
  2. Tap Share, then Add to Home Screen, then Add.

It opens full screen and works without signal using the last menus it downloaded.

Reading the tags

  • As listed gluten free with no changes
  • Any milk fine with any of the options shown
  • Swap normally comes with an option that has gluten, so ask for another
  • Ask gluten free only with the change shown
  • Wheat contains gluten whatever you order

Favourites

Open any item and tap ☆ Save. Favourites stay on this phone.

Staying up to date

The app checks for new menus each time you open it with signal. Tap ↻ to check now. If a restaurant's guide has passed its end date, you'll see a warning.
